🦅 Eagle GCP Exporter (v2.0)

Eagle GCP Exporter è una suite web-based client-side (offline e 100% privata) per l'elaborazione di rilievi laser scanner SLAM. Gestisce l'estrazione dei GCP, la bonifica dei dati, l'allineamento 3D, l'export CAD e la documentazione fotografica delle stazioni.
🌟 Caratteristiche Principali

    Estrazione GCP: parsing automatico di TRJ.txt, ControlPoint.txt e calib.json con rilevamento delle soste.

    Bonifica & Duplicati: fusione o filtraggio automatico delle registrazioni multiple.

    Allineamento 3D: livellamento su piano e rototraslazione rigida (Horn's Quaternion Method) su punti target con calcolo RMS.

    Visualizzatore 2D & Sfondo PCD: canvas interattivo con supporto a nuvole .pcd (ASCII, Binary, LZF) fino a 2,5M+ di punti.

    Field-to-Finish CAD: vestizione grafica automatica dei punti (alberi, pozzetti, siepi, muri) ed export DXF 2D/3D e CSV.

    Virtual Tour 360°: associazione automatica foto-stazione (da Colmap/images), visore a schermo intero ed export in Webgallery HTML standalone.

🚀 Utilizzo

Scarica il file Eagle-GCP-Exporter_v_2.0.html ed aprilo in qualsiasi browser web. Nessuna installazione o server richiesto.

🦅 Eagle GCP Exporter (v2.0)

Eagle GCP Exporter is a 100% private, offline, client-side web suite designed to process SLAM laser scanner surveys. It automates GCP extraction, data deduplication, 3D alignment, CAD export, and station photographic documentation.
🌟 Key Features

    GCP Extraction: Automatic parsing of TRJ.txt, ControlPoint.txt, and calib.json with static stop detection.

    Deduplication: Multi-registration filtering and coordinate averaging.

    3D Alignment: Plane leveling and rigid 3D rototranslation (Horn's Quaternion Method) with real-time RMS calculation.

    2D Viewer & PCD Raster: Interactive canvas supporting .pcd point clouds (ASCII, Binary, LZF) up to 2.5M+ points.

    Field-to-Finish CAD: Automatic symbol classification (trees, manholes, hedges, walls) and direct export to 2D/3D DXF and CSV.

    360° Virtual Tour: Automatic photo-to-station matching (from Colmap/images), full-screen interactive gallery, and standalone HTML Webgallery export.

🚀 Getting Started

Download Eagle-GCP-Exporter_v_2.0.html and open it in any modern web browser. No installation or server required.
